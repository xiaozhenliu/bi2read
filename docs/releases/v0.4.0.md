# BiMyScribe v0.4.0

本版本交付可信的中英文转写：Runtime 升级到 contract v2，用户可以为中文、英文视频
明确选择转写语言，任务身份与实际处理配置全程可核对，产品不静默代替用户切换。

## 主要变化

- Runtime 契约升级到 v2：中文路由 `paraformer-zh`，英文路由映射 damo 英文权重的
  `paraformer-en`，`auto` 先用 SenseVoiceSmall 检测语言再路由，检测失败不回退。
- 提交任务前新增转写确认流程：显示所选 Runtime 的来源、模型、建议语言与已知限制，
  语言选择（auto/zh/en）由用户显式做出并随任务冻结。
- 冻结的选择持久化在任务状态中：重试、恢复与重跑都不会被当前设置改变；Runtime
  身份变化会在启动适配器前明确失败，而不是悄悄换模型。
- 转写结果回报实际使用的语言、模型与 Runtime 身份，写入 Evidence 供核对。
- v1 Runtime 仍可读取和显示，但创建新任务时返回稳定的“需要升级”错误。
- CLI 新增稳定 JSON 契约：统一信封、稳定错误码与退出码，交互中不阻塞、不静默
  回退，便于 Agent 安全调用。
- 旧版本创建的无语言记录任务标记为需要用户操作，要求以显式设置重建，不猜测。

## 兼容性与升级

- 升级到本版本后，首次转写会提示选择新的 Runtime（FunASR Runtime v2.0.0）；
  旧 v1 Runtime 不再用于新任务。
- 旧任务的原始 Evidence 保持可读；无语言记录的任务需要以显式转写设置重建。
- uv 仍为 0.11.23；仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 面向单一主要语言的视频；混合语言与低置信输入需要人工核对。
- 尚不提供官方签名、公证的 DMG；界面固定为浅色。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。

## English

### Highlights

- Runtime contract upgraded to v2: Chinese routes to `paraformer-zh`, English
  routes to `paraformer-en` mapped to the damo English weights, and `auto`
  detects the language with SenseVoiceSmall before routing — detection failure
  never silently falls back.
- A transcription confirmation step before submitting a job shows the selected
  runtime's source, model, recommended languages and known limitations; the
  language choice (auto/zh/en) is explicit and frozen with the job.
- The frozen selection is persisted in job state: retry, recovery and reruns are
  never overridden by current settings, and a changed runtime identity fails
  loudly before the adapter launches instead of quietly swapping models.
- Transcription results report the language, model and runtime identity actually
  used, recorded in the evidence for verification.
- v1 runtimes remain readable and displayable, but new jobs return a stable
  upgrade-required error.
- The CLI gained a stable JSON contract: one envelope, stable error codes and
  exit codes, no interactive blocking and no silent fallback — safe for agents.
- Jobs created by older versions without a language record are marked as
  needing user action and must be rebuilt with explicit settings, never guessed.

### Compatibility and upgrades

After upgrading, the first transcription prompts you to select the new runtime
(FunASR Runtime v2.0.0); the old v1 runtime is no longer used for new jobs. Raw
evidence from old jobs stays readable; jobs without a language record must be
rebuilt with explicit transcription settings. uv stays at 0.11.23. macOS 13 or
newer on Apple Silicon is supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple
Silicon macOS, run `scripts/build-macos-local.sh`; press Enter for ad-hoc
signing suitable for the machine that built it. FFmpeg must be installed
separately and available on `PATH`.

### Known limitations

Best suited to videos with one dominant language; mixed-language and
low-confidence input needs manual review. No officially signed and notarized
DMG is provided yet, and the interface is light-mode only. FFmpeg is external,
and first-time ASR setup downloads models.
