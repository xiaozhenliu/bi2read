# BiMyScribe v0.6.0

本版本交付智能文字处理与精选能力，在已建立的可信文字消费闭环上新增 AI 连接测试诊断、
模型更换提示与针对性重新生成、短/标准/长三档摘要与 Schema v2、单视频文字与说话人搜索，
以及可解释的版本化阅读时间与预计节省估算。

## 主要变化

- **AI 连接测试（F1）**：在设置弹窗中支持测试本地 OpenAI/Anthropic 兼容服务连接，
  具备 10 秒硬性超时与本机 Loopback 严格地址校验；结构化诊断地址无效、服务不可达、
  协议不匹配、模型不存在或超时；具备草稿状态与异步回写隔离，不阻塞设置保存。
- **模型更换提示与重生成（F2）**：当设置中的 AI 模型变更时，在文字结果顶部以中性提示条
  显示模型变更通知（`{旧模型} → {新模型}`），各增强操作旁注显示将使用的模型；支持从
  既有 Evidence 针对性重新生成各文字档位并记录生成身份，无需重新运行 ASR。
- **短/标准/长三档摘要与 Schema v2（F3）**：结果视图摘要页新增三档深度分段选择；三档具备
  独立的长度与来源映射契约；未生成档位提供平滑空状态与针对性生成按钮；选中未生成档位时
  直接回退忠实正文，`full.md` 严格按选定档位导出；发布格式升级为 `content-current.v1.json`
  Schema v2 并向后兼容 v1。
- **单视频文字搜索（F4）**：支持在消费结果中对忠实正文与原始转写进行关键词搜索；
  支持 `mm:ss` / `hh:mm:ss` 时间点（±30 秒）与 `start-end` 时间范围过滤，以及说话人
  过滤；支持上下文关键词高亮与原片时间跳转。
- **版本化阅读时间估算（F5）**：基于纯中、纯英及中英混排正文字数规模，提供版本化阅读时间
  与原视频时长节省估算；界面提供“如何计算”展开式依据说明；单任务 UI 与 `full.md` 共享
  同一估算口径。

## 兼容性与升级

- 从 v0.5.x 升级完全兼容：既有 `content-current.v1.json`（Schema v1）可直接无缝读取并在内存中
  扩展为空 tier 档位；下一次内容更新自动写入 Schema v2。
- 任务队列与设置配置无需迁移。
- Runtime 固定输入保持 FunASR v2.0.0（contract 2），uv 保持 0.11.23。
- 仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 单视频搜索目前覆盖忠实正文与原始转写，暂不跨视频全局检索。
- AI 连接测试仅向用户填写的本地服务地址发送测试请求，BiMyScribe 本身不下载或启动 LLM 模型。
- 尚不提供官方签名、公证的 DMG；界面固定为浅色。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。
- 图文精读、关键帧提取与图片内容包属于后续 v0.7.0 规划阶段。

## English

This release delivers smart text curation capabilities on top of the trusted text consumption foundation,
adding AI connection test diagnostics, model changed notices with targeted regeneration, short/standard/long
summary tiers with Schema v2, single-job text and speaker search, and versioned reading time estimation.

### Highlights

- **AI Connection Test (F1)**: Test local OpenAI/Anthropic-compatible endpoints in Settings with strict loopback
  address validation and a 10s deadline, classifying failures into InvalidAddress, Unreachable, ProtocolMismatch,
  ModelUnavailable, or Timeout with draft-isolation guarantees.
- **Model Changed Notice & Regeneration (F2)**: Notify when the configured model differs from the latest generation
  provenance (`{old} → {new}`), displaying target model notes and supporting targeted slot regeneration without
  re-running ASR.
- **Three-tier Summary & Schema v2 (F3)**: Segmented control switches between Short, Standard, and Long summary
  tiers with independent length and source contracts, clean empty states, direct fallback to faithful body text,
  and tier-consistent `full.md` export.
- **Single-job Text Search (F4)**: Filter across faithful text and raw transcripts with keyword search, timestamp
  (±30s) or range filtering, speaker filtering, snippet highlighting, and video time jumps.
- **Versioned Reading Time Estimation (F5)**: Estimate reading time and video time saved across Chinese, English,
  and mixed scripts with a collapsible explanation accordion in the UI and metadata in `full.md`.

### Compatibility and upgrades

Upgrades from v0.5.x are seamless. Schema v1 `content-current.v1.json` files parse directly with empty tier slots
and save as Schema v2 upon new updates. Runtime inputs remain FunASR v2.0.0 (contract 2) and uv 0.11.23. macOS 13
or newer on Apple Silicon is supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple Silicon macOS, run
`scripts/build-macos-local.sh`; press Enter for ad-hoc signing suitable for the machine that built it.
FFmpeg must be installed separately and available on `PATH`.

### Known limitations

Search is scoped to the active job and covers faithful text and raw transcripts. Connection test probes user-provided
endpoints and does not manage or pull LLM models. Illustrated content packages and keyframes are scheduled for v0.7.0.
