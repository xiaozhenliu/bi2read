# BiMyScribe v0.2.2

本版本改进长篇转写的阅读体验，并延续可复现的本机构建流程。用户无需 Apple Developer 会员，即可从源码生成适合当前机器自用的 ad-hoc 签名 `BiMyScribe.app`。

## 主要变化

- 阅读稿会确定性合并相邻且 Speaker 相同的短片段，每个连续发言块只保留起始时间链接。
- 合并过程不调用 LLM，不增删或改写转写文本；逐片段原始稿继续保留全部时间链接。
- 新增 `scripts/build-macos-local.sh`，一条命令下载固定版本依赖、构建并签名 App。
- 新增 BiMyScribe App 图标，并写入 macOS 应用包元数据。
- 新任务工作目录采用“创建时间、视频标识、分 P、UUID 短后缀”的可读名称。
- 已有任务继续使用原工作目录，无需迁移；完整 UUID 仍作为内部唯一身份。
- App 内置 FunASR Runtime v1.0.0 与 uv 0.11.23，并自动发现内置 Runtime。
- 自定义原生 Runtime 与 Docker Runtime 仍可在设置中选择，并优先于内置 Runtime。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行 `scripts/build-macos-local.sh`。直接回车使用适合本机自用的 ad-hoc 签名。FFmpeg 仍需单独安装并位于 `PATH`。

## 兼容性与升级

- 当前仅支持 Apple Silicon macOS 13 或更高版本。
- 已有设置、任务数据和 Markdown 输出不会因升级而删除。
- Runtime 指纹变化时，应用可能要求重新安装或验证 Runtime。

## 已知限制

- 尚不提供官方签名、公证的 DMG。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。

## English

### Highlights

- Adjacent transcript segments from the same speaker are grouped deterministically with one starting seek link.
- Grouping never calls an LLM or edits transcript text; raw Markdown retains every timestamp.
- The reproducible local macOS build pins Runtime v1.0.0 and uv 0.11.23.
- New jobs use readable directory names; existing jobs require no migration.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple Silicon macOS, run `scripts/build-macos-local.sh`; press Enter for ad-hoc signing suitable for the machine that built it. FFmpeg must be installed separately and available on `PATH`.

### Compatibility and upgrades

macOS 13 or newer on Apple Silicon is supported. Existing settings, jobs, and Markdown outputs are preserved. A changed Runtime fingerprint can require Runtime reinstallation or verification.

### Known limitations

No officially signed and notarized DMG is provided yet. FFmpeg is external, and first-time ASR setup downloads models.
