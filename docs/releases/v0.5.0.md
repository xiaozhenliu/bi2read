# BiMyScribe v0.5.0

本版本把转写结果扩展为可阅读、可核对的可信文字消费闭环。新任务完成后可以在应用内查看
忠实正文、章节、默认摘要、重点与原始稿；每项派生内容都会明确显示可核对来源或来源受限状态。

## 主要变化

- 新增消费结果视图，可在摘要、章节、忠实正文和原始稿之间切换；任务信息始终保留 BVID、
  分 P 与时长。
- 忠实正文由已验证 Evidence 派生并保留逐片段映射；章节、摘要和重点支持展开来源片段并跳回
  原视频。无法可靠映射时明确显示来源受限，不伪造链接。
- 章节、摘要和重点可单项重新生成；重新生成不重复下载、FFmpeg 或 ASR，不改变任务终态，
  失败时保留当前结果并显示可行动提示。
- 使用 `content-current.v1.json` 保存当前结构化内容事实，并继续保留唯一最终 `full.md` 出口；
  原始 Evidence 始终可访问，派生增强失败不会覆盖它。
- 长内容生成采用分块、层级合并和覆盖校验；删除、幻觉、异常压缩或无效来源映射会失败或回退。

## 兼容性与升级

- 从 v0.4.1 升级无需迁移设置、队列或旧任务。缺少 v0.5 marker 的旧任务继续使用既有兼容路径，
  不会从旧 Markdown 反推新结构化结果。
- Runtime 固定输入保持 FunASR v2.0.0（contract 2），uv 保持 0.11.23。
- 仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 可信消费结果只对带有效 Evidence marker 的新终态任务开放；旧任务保持兼容行为。
- 单项重新生成只保留当前结果，不提供生成历史、回滚、提示模板编辑或模型切换。
- 面向单一主要语言的视频；混合语言与低置信输入需要人工核对。
- 尚不提供官方签名、公证的 DMG；界面固定为浅色。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。
- 尚不包含全文搜索、翻译、截图、OCR 或图文内容包。

## English

This release turns transcription output into a readable, verifiable text-consumption flow. After a new job
finishes, the app can show faithful text, chapters, a default summary, highlights, and the raw transcript;
each derived item explicitly reports mapped or limited source status.

### Highlights

- A result view switches between summary, chapters, faithful text, and raw transcript while keeping the BVID,
  part number, and duration visible.
- Faithful text derives from validated Evidence and retains per-segment mappings. Chapters, summary, and
  highlights can expand source excerpts and jump back to the video; unreliable mappings are marked limited
  and never become fabricated links.
- Chapters, summary, and highlights can be regenerated independently without repeating download, FFmpeg, or
  ASR work. Regeneration does not change the terminal job state; failure keeps the current result and shows an
  actionable message.
- `content-current.v1.json` stores the current structured content fact while `full.md` remains the single final
  document output. Raw Evidence remains accessible and cannot be overwritten by an enhancement failure.
- Long content uses chunking, hierarchical merging, and coverage checks. Deletion, hallucination, abnormal
  compression, and invalid source mappings fail validation or fall back safely.

### Compatibility and upgrades

No settings, queue, or legacy-job migration is needed from v0.4.1. Jobs without the v0.5 marker keep their
existing compatibility path; the app does not infer new structured results from old Markdown. Runtime inputs
remain FunASR v2.0.0 (contract 2) and uv 0.11.23. macOS 13 or newer on Apple Silicon is supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple Silicon macOS, run
`scripts/build-macos-local.sh`; press Enter for ad-hoc signing suitable for the machine that built it.
FFmpeg must be installed separately and available on `PATH`.

### Known limitations

Trusted results open only for new terminal jobs with a valid Evidence marker; legacy jobs keep their
compatibility behavior. Regeneration retains only the current result and provides no generation history,
rollback, prompt-template editing, or model switching. Mixed-language and low-confidence input needs manual
review. No officially signed and notarized DMG, dark mode, full-text search, translation, screenshot extraction,
OCR, or illustrated content package is provided. FFmpeg is external, and first-time ASR setup downloads models.
