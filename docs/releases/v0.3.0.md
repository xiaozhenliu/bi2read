# BiMyScribe v0.3.0

本版本重做了整个界面视觉层：主色换成 B 站品牌粉，中性色转暖，任务队列改为卡片式，
任务状态按阶段语义着色。信息架构、滚动行为与数据处理逻辑保持不变，升级不影响已有任务。

## 主要变化

- 主色改为 B 站品牌粉，辅以下载青与 AI 润色紫；中性色整体转暖，圆角放大到 6/8/12。
- 任务队列改为卡片式：卡片间留白、选中态浅粉底加左侧粉色指示条、失败任务红色描边。
- 任务状态按阶段语义化：排队灰、下载青、转写粉、AI 润色紫、完成绿、失败红，
  每种颜色都配文字标签，颜色不作为唯一信号。
- 任务详情新增状态徽章，进度条与百分比跟随当前阶段配色；操作按钮改为右对齐。
- 阶段历史改用图标区分完成、进行中、等待、跳过与错误五种状态。
- 检查器分页改为分段控件；说话人配置显示每位说话人的片段数（“出现 N 段”）。
- 创建工具栏加入应用标识，链接输入框内置图标，设置改为图标按钮。
- 设置弹窗改版：左侧导航选中态为白底加粉色指示条，开关改为品牌粉样式，
  标题栏在有未保存改动时给出提示。
- 键盘焦点环改用深粉色，禁用按钮文字提高对比度，弱化文字整体加深，
  以满足 WCAG AA 的可读性要求。

## 兼容性与升级

- 仅视觉层变化，任务数据、设置、Markdown 输出与工作目录结构均不变。
- 内置 FunASR Runtime 仍为 v1.0.0、uv 仍为 0.11.23，无需重新安装 Runtime。
- 当前仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 尚不提供官方签名、公证的 DMG。
- 界面固定为浅色，暂不跟随系统深色模式。
- 详情页暂不显示“预计剩余时间”。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。

## English

### Highlights

- The interface was restyled around the Bilibili brand pink, with warmer neutrals
  and larger corner radii (6/8/12).
- The task queue is now card-based, with a pink indicator bar on the selected card
  and a red outline on failed jobs.
- Task state is colour-coded per stage — queued grey, download cyan, transcribe pink,
  AI polish purple, done green, failed red — always paired with a text label.
- Task detail gained a status badge; the progress bar and percentage follow the
  current stage colour, and actions are right-aligned.
- Stage history uses distinct icons for done, active, waiting, skipped and error.
- The inspector uses a segmented control, and speaker configuration shows the
  number of segments per speaker.
- Focus rings, disabled button text and muted text were darkened to meet WCAG AA.

### Compatibility and upgrades

This is a visual-layer release. Job data, settings, Markdown output and working
directory layout are unchanged. The bundled FunASR Runtime stays at v1.0.0 and uv
at 0.11.23, so no Runtime reinstallation is required. macOS 13 or newer on Apple
Silicon is supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple
Silicon macOS, run `scripts/build-macos-local.sh`; press Enter for ad-hoc signing
suitable for the machine that built it. FFmpeg must be installed separately and
available on `PATH`.

### Known limitations

No officially signed and notarized DMG is provided yet. The interface is
light-mode only. Estimated remaining time is not shown. FFmpeg is external, and
first-time ASR setup downloads models.
