# BiMyScribe v0.5.1

本修复版本移除公开源码归档中指向内部排除文档的失效链接。产品行为、Runtime、数据格式和
安装方式与 v0.5.0 相同。

## 主要变化

- ADR-0001 与 ADR-0002 不再链接未随公开快照发布的内部 PRD 和归档 Design Plan；交互依据改为
  公开可达的当前 Design Spec，产品依据保留为不带内部路径的文字说明。
- v0.4.0 历史 design-plan 指针不再链接被排除的归档副本，最终设计入口继续指向当前 Design Spec。
- 公开源码归档不再包含对上述排除材料的失效引用。
- 匿名 Runtime Release 核验使用 GitHub 标准 API 请求头和唯一查询参数，避免重复命中边缘节点
  缓存的 504 响应；核验仍不使用登录凭据。

## 兼容性与升级

- 与 v0.5.0 完全兼容；设置、队列、任务、Evidence 和 `content-current.v1.json` 均无需迁移。
- Runtime 固定输入保持 FunASR v2.0.0（contract 2），uv 保持 0.11.23。
- 仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 产品能力与限制和 v0.5.0 相同；本版本只修复公开文档引用。
- 尚不提供官方签名、公证的 DMG；界面固定为浅色。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。

## English

This patch removes broken links from the public source archive to internal excluded documents. Product
behavior, Runtime inputs, data formats, and installation remain unchanged from v0.5.0.

### Highlights

- ADR-0001 and ADR-0002 no longer link to internal PRDs or archived design plans that are absent from the public
  snapshot. Interaction references now point to the public Design Spec, while product bases remain plain text.
- The historical v0.4.0 design-plan pointer no longer links to an excluded archive copy and continues to direct
  readers to the current public Design Spec.
- The public source archive no longer contains broken references to those excluded materials.
- Anonymous Runtime Release verification uses standard GitHub API headers and a unique query parameter to avoid
  repeatedly hitting a cached edge 504; verification still uses no login credentials.

### Compatibility and upgrades

This release is fully compatible with v0.5.0. Settings, queue entries, jobs, Evidence, and
`content-current.v1.json` need no migration. Runtime inputs remain FunASR v2.0.0 (contract 2) and uv 0.11.23.
macOS 13 or newer on Apple Silicon is supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple Silicon macOS, run
`scripts/build-macos-local.sh`; press Enter for ad-hoc signing suitable for the machine that built it.
FFmpeg must be installed separately and available on `PATH`.

### Known limitations

Product capabilities and limitations are unchanged from v0.5.0; this patch only repairs public documentation
references. No officially signed and notarized DMG or dark mode is provided. FFmpeg is external, and first-time
ASR setup downloads models.
