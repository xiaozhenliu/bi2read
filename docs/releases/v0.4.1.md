# BiMyScribe v0.4.1

本版本补齐转写历史管理：用户可以删除单个已结束任务，或一键清空全部已结束的
历史记录，任务列表不再随使用无限累积。Runtime 与转写能力与 v0.4.0 保持一致。

## 主要变化

- 已完成、失败、已取消的任务详情新增“删除任务”操作；排队或运行中的任务不能
  删除，需要先取消。
- 任务队列新增“清空历史”入口：一次性删除全部已结束任务，排队与运行中的任务
  不受影响。
- 删除与清空都经过确认弹窗，明确说明将删除任务记录与全部产物文件且不可撤销；
  Escape 或“取消”不产生任何变更。
- 删除会同时移除任务记录、任务工作目录（含状态文件）和该任务专属的输出目录；
  外置盘未连接时视为产物已不存在，删除后重启应用任务不会重新出现。
- 删除当前选中的任务后，自动选中相邻任务；队列清空后回到空状态。

## 兼容性与升级

- 从 v0.4.0 升级无需迁移：设置、队列与既有任务格式不变；Runtime 仍为
  FunASR v2.0.0（contract 2），uv 仍为 0.11.23。
- 删除操作不可撤销；需要保留产物的任务请先自行备份输出目录。
- 仅支持 Apple Silicon macOS 13 或更高版本。

## 安装

本 Release 不提供官方签名并经 Apple 公证的 DMG。Apple Silicon Mac 可从源码运行
`scripts/build-macos-local.sh`，直接回车使用适合本机自用的 ad-hoc 签名。
FFmpeg 仍需单独安装并位于 `PATH`。

## 已知限制

- 面向单一主要语言的视频；混合语言与低置信输入需要人工核对。
- 尚不提供官方签名、公证的 DMG；界面固定为浅色。
- FFmpeg 需要单独安装；ASR 首次安装需要下载模型。
- 不提供归档（导出后移除）与基于时间的自动清理。

## English

### Highlights

- Completed, failed and cancelled jobs gain a "Delete task" action in the task
  detail; queued or running jobs cannot be deleted and must be cancelled first.
- The task queue gains a "Clear history" entry that removes every finished job
  at once while leaving queued and running jobs untouched.
- Both actions go through a confirmation dialog that spells out what will be
  removed and that it cannot be undone; Escape or "Cancel" changes nothing.
- Deleting removes the queue record, the job's working directory (including its
  state file) and the job's own output directory; an unplugged external drive
  counts as already gone, and deleted jobs never reappear after a restart.
- After deleting the selected task, the neighbouring task is selected
  automatically; clearing the last task returns the queue to its empty state.

### Compatibility and upgrades

No migration is needed from v0.4.0: settings, the queue and existing job formats
are unchanged. The runtime stays FunASR v2.0.0 (contract 2) and uv stays
0.11.23. Deletion cannot be undone; back up an output directory before deleting
a task whose artifacts you still need. macOS 13 or newer on Apple Silicon is
supported.

### Installation

This release does not provide an officially signed and notarized DMG. On Apple
Silicon macOS, run `scripts/build-macos-local.sh`; press Enter for ad-hoc
signing suitable for the machine that built it. FFmpeg must be installed
separately and available on `PATH`.

### Known limitations

Best suited to videos with one dominant language; mixed-language and
low-confidence input needs manual review. No officially signed and notarized
DMG is provided yet, and the interface is light-mode only. FFmpeg is external,
and first-time ASR setup downloads models. Archiving (export-then-remove) and
time-based automatic cleanup are not provided.
