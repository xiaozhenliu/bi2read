# ADR-0003：产品更名为 bi2read

状态：Accepted（品牌与身份决策；实施按维护者内部改名方案执行）
日期：2026-09-09
影响范围：产品品牌、公开仓库身份、代码与打包身份、文档口径

## 背景

产品当前名称 BiMyScribe 是"Bi（Bilibili）+ My + Scribe"的组合，对中文用户不直观，
也不直接表达产品定位——"不看视频就获得知识，把长视频变成可阅读的内容"。

启用新名字前对候选名称做了占用调研（2026-09-09，通过 GitHub 搜索、Exa 网页搜索、
DNS-over-HTTPS 与包注册表查询）：

- **zimuji（字幕机）**：被同类商业产品 V2sub「AI字幕机」（zimuji.com，已 ICP 备案、
  GitHub 组织 `aizimuji`、分版本收费的字幕生成软件）完整占用，且与本品同为
  ASR + LLM 工具，存在直接的品牌混淆与 SEO 竞争。排除。
- **bibook**：`bibook.com`/`.app`/`.net` 均被活跃产品占用（BI 数据平台、德国书籍翻译
  服务、非洲阅读 App），GitHub 上亦有多个同名双语电子书项目。语义场拥挤。排除。
- **bi2read**：GitHub 搜索零结果；`bi2read.com`/`.app`/`.io`/`.dev`/`.net` 经
  Cloudflare DoH 核验均为 NXDOMAIN（未注册）；PyPI、npm、crates.io 均未占用。
  已知最近邻是浏览器插件 BiRead（biread.com，面向英文用户的网页双语翻译工具），
  读音相近但品类不同、中文圈存在感极低；本产品只面向中文用户，该混淆可接受。

对中文用户："bi" 即"哔"，直接唤起 Bilibili 联想；"2" 读作 "to"（V2EX、v2ray 的
既有惯例）；"read" 是义务教育词汇。名字整体读作 "bi to read"，表达"把 B站视频变成
可读内容"，与 PRD 2.1 的一句话定位一致。

## 决策

1. **产品对外名称改为 bi2read**，全部小写。UI 显示名、README、用户文档、发布资产名、
   公开仓库名统一使用 `bi2read`。
2. **产品是非商业开源项目，不购买域名**。域名注册仅作为可选的防御性动作，由维护者
   自行决定时机；品牌落地的必要动作只有 GitHub 组织/仓库占名与公开发布口径更新。
3. **持久化数据契约不随品牌改名**。ADR-0002 冻结的 Evidence identity domain 字符串
   `bimyscribe/evidence/v1` 原样保留——它已写入既有任务的 `content-current.v1.json`，
   改动会使既有产物无法通过身份复核。代码注释中说明该字符串是历史名称，不是品牌。
4. **机器身份（Cargo 包名、二进制名、`.app` 名、Bundle ID、用户数据目录、环境变量）
   随品牌一次改清**，不长期维持新旧双名。当前产品处于 v0.x、用户基数为维护者本人
   与少量源码自构建用户，一次性切换的成本低于双名并存的长期混淆。
5. **历史文档不改名**。归档的历史设计与方案、已发布的版本化 Release Notes（
   `docs/releases/v0.2.2`—`v0.6.0`）和 CHANGELOG 中既有条目保留 BiMyScribe 原文；
   它们是历史事实，不是当前品牌。PRD、Design Spec、Architecture、README 等持续
   演进的权威文档切换到新名。
6. **改名在下一个公开发布前完成**，使公开仓库历史只出现 bi2read 一个正式身份；
   若公开仓库已经以 bimyscribe 名义存在 Release，则通过 GitHub rename 保留重定向，
   并在改名后的首个 Release Notes 中说明更名事实。

## 取舍

- 一次改清机器身份会让维护者本机既有配置、Runtime 就绪记录和队列状态落在旧目录
  下。改名方案要求提供一次性目录迁移（新目录不存在且旧目录存在时执行 rename），
  而不是双路径兼容逻辑——个人工具不为一次性迁移预付长期复杂度。
- 保留 `bimyscribe/evidence/v1` 意味着代码中长期存在一个旧名字符串。它以注释标记
  为冻结契约，任何"顺手统一命名"的修改都属于破坏既有用户数据。
- GitHub 仓库 rename 的旧 URL 重定向在转移或新建同名仓库后失效；改名方案把
  外部引用（文档、脚本中的仓库地址）一并更新，不依赖重定向长期有效。
- 中文副品牌（如"哔读"）暂不确定。bi2read 单独作为唯一品牌先落地；若后续社区
  传播需要中文名，再以新决策补充，不预先注册语义。

## 验证

- 改名实施完成后：`cargo test`、UI 实机验收（含设置弹窗与两档尺寸）通过；
  全新状态安装包首次运行显示 bi2read 身份；从旧目录迁移的安装能读取既有任务
  与配置。
- 公开发布门禁（`scripts/check-release.sh`）在新名字下完整跑通一次，证明发布
  身份切换没有遗漏。
