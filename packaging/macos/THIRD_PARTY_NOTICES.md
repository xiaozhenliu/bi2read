# Bundled third-party executable

The macOS application bundle includes the `uv` executable from Astral under
the dual MIT and Apache-2.0 licenses. The corresponding license texts are
included beside this notice.

The bundled BiMyScribe FunASR Runtime contains its own `LICENSE` and
`THIRD_PARTY_NOTICES.md`. Python packages and model weights are installed into
the user-selected Runtime data directory and are not embedded in the app.
